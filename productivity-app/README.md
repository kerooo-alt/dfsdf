# 🌊 FlowFocus

Удобное приложение для продуктивной работы по **блокам фокуса**: таймер Pomodoro, задачи с отметками выполнения, настраиваемый трекер ежедневных рутин, живые анимированные фоны и синтезированные звуки. Работает полностью офлайн — просто откройте `index.html` в браузере.

## Запуск

```bash
# вариант 1: открыть файл напрямую
open index.html          # macOS
xdg-open index.html      # Linux

# вариант 2: локальный сервер
python3 -m http.server 8000   # затем http://localhost:8000
```

## Возможности

### 🎯 Фокус-блоки
- Круговой таймер с плавным кольцом прогресса и пульсацией во время работы
- Циклы «фокус → короткий перерыв → длинный перерыв» (настраиваются)
- Быстрые пресеты: 15 / 25 / 45 / 52 / 90 минут
- Планировщик блоков на день: блок можно привязать к задаче и запустить одним кликом ▶
- Автозапуск перерывов и следующих блоков (по желанию)
- Таймер виден во вкладке браузера

### ✅ Задачи
- Приоритеты 🔥 / ⭐ / 🌱, фильтры «Все / Активные / Готово»
- Красивая анимация чекбокса + звуковой «дзынь» при выполнении
- Конфетти при закрытии всех задач 🏆
- Кнопка 🎯 — мгновенный фокус-блок на выбранной задаче
- Ротация советов по постановке задач

### 🔄 Рутины
- Ежедневные ритуалы с временем и днями недели (полная гибкая настройка)
- Прогресс-бар дня, недельная сетка-трекер, личные серии 🔥 каждой рутины
- Общая серия продуктивных дней (streak) в шапке

### 🌊 Живые фоны (Canvas-анимации)
- **Море** — волны, блики солнца, чайки
- **Ветреное поле** — гнущаяся от порывов ветра трава, летящие пушинки, облака
- **Ночное небо** — мерцающие звёзды, луна, падающие звёзды
- **Северное сияние**, **Дождь** (с молниями), либо без фона
- Регулировка интенсивности анимации

### 🔊 Звук (Web Audio API, всё синтезируется — без файлов)
- Тёплый аккорд на старт блока, колокольчиковая каденция на завершение
- Приятный «дзынь» для отметок задач, мягкие тики
- Генеративный белый шум во время фокуса: 🌊 волны, 🍃 ветер, 🌧 дождь, ☕ кафе
- Громкость, тесты звуков, общий mute

### 💡 Памятки
Коллекции карточек: методики фокуса (Pomodoro, Deep Work, «съешьте лягушку», time-blocking), привычки и рутины (habit stacking, «не прерывай цепочку»), энергия и здоровье, вдохновляющие цитаты. Плюс «мысль дня» на главной.

### ⚙️ Дополнительно
- Тёмная/светлая тема, 5 акцентных цветов
- Статистика дня: блоки, минуты фокуса, выполненные задачи
- Экспорт/импорт данных в JSON, сброс
- Сохранение всего в localStorage
- Горячие клавиши: `Пробел` — старт/пауза, `1–5` — вкладки, `Esc` — закрыть окно
